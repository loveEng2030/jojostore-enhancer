# نسخة PDF تبدو كالموقع بالضبط

## الفكرة
PDF لا يستطيع تشغيل فيديو أو تمرير حقيقي، لكنه يستطيع أن يبدو ويعمل مثل الموقع تقريبًا:
- كل صفحة من صفحات الموقع تُصوَّر بالكامل بشكلها الحقيقي (نفس الألوان، الصور، الخطوط، التخطيط).
- الروابط داخل الـPDF تعمل: الضغط على عنصر في القائمة العلوية ينقلك لصفحة أخرى داخل نفس الملف، وزر واتساب يفتح واتساب فعليًا.
- الفيديو في الصفحة الرئيسية يظهر كصورة ثابتة من أول مشهد (لأن PDF لا يشغّل فيديو).

## ما سيحتويه الملف
1. الرئيسية
2. الكتالوج (كل المنتجات)
3. تجار مصر + نموذج البيانات
4. التصدير الخارجي
5. قصتنا
6. الأسئلة الشائعة
7. تواصل معنا

## طريقة التنفيذ
- فتح كل صفحة في متصفح داخلي بمقاس عريض، والانتظار حتى تحميل كل الصور، ثم تصوير الصفحة كاملة بدون تقطيع في منتصف قسم.
- كل صفحة موقع = صفحة PDF واحدة طويلة (أو مقسّمة عند حدود الأقسام فقط)، حتى يبدو التصفح طبيعيًا.
- إضافة فهرس في أول الملف بروابط داخلية لكل صفحة، وشريط تنقل قابل للضغط أعلى كل صفحة.
- تحويل الروابط الخارجية (واتساب، الهاتف) إلى روابط قابلة للضغط.
- مراجعة كل صفحة بصريًا قبل التسليم: لا نصوص مقطوعة، لا مساحات فاضية، لا صور ناقصة.

## تفاصيل فنية
- Playwright Chromium بمقاس 1440 عرض، `print_background=True`، تعطيل الحركات/الأنيميشن قبل التصوير.
- استبدال عنصر الفيديو بصورة الـposter قبل الطباعة.
- دمج الصفحات وإضافة الروابط الداخلية عبر pypdf.
- الملف النهائي: `/mnt/documents/jojo-store-web-view.pdf` (نسخة جديدة، دون المساس بالملف القديم).

لا تعديل على كود الموقع نفسه.
